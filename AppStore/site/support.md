# 拾页技术支持 / Shiye Support

拾页将网站、书签、图文笔记和文件放在同一处，并通过 iCloud 在 iPhone 与 Mac 之间同步。

Shiye organizes websites, bookmarks, illustrated notes and files, with iCloud synchronization between iPhone and Mac.

## 同步 / Sync

两端需要使用相同的 iCloud 账户，并在系统设置中启用 iCloud。收藏先保存在设备资料库，大文件需要等待上传及下载完成。网络状态、iCloud 空间和后台调度会影响到达时间。

Use the same iCloud account and enable iCloud on both devices. Items save to the local app library first. Large attachments require time to upload and download. Network conditions, available iCloud storage and background scheduling affect delivery time.

## 备份 / Backups

在“导出数据”中设置独立的备份密码。新版 .shiye 备份包括文件内容，也继续支持旧版 JSON 备份导入。导入保留本机独有内容。开发者无法找回遗失的备份密码。

Choose a separate backup password when exporting. New .shiye backups include file content, and older JSON imports remain supported. Imports retain items unique to the current device. The developer cannot recover a lost backup password.

## 密码 / Passwords

开机密码和删除分组密码在“系统设置”中修改。开机密码用于当前设备的界面访问验证。

Change the launch password and group-deletion password in System Settings. The launch password controls interface access on the current device.

## 链接信息 / Link metadata

标题与介绍由目标网站提供。部分网站需要网络、登录或限制自动读取，此时可以编辑书签并手动填写。

Titles and descriptions are supplied by the destination website. Some sites require connectivity or sign-in, or restrict automated reading. Edit a bookmark to enter details manually when needed.
