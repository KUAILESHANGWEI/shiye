# 拾页

一个简洁的 macOS 网站收藏工具。可按分组整理网站名称、链接和备注，支持搜索、拖动排序、密码保护，以及加密备份的导入与导出。

## 系统要求与构建

需要 Apple Silicon Mac、macOS 13 或更高版本，以及 Apple Command Line Tools。运行：

```sh
./build-preview.sh
```

生成 `拾页预览.app`。此构建使用临时签名，未经过 Apple 公证。

## 数据与备份

收藏保存在本机应用支持目录。云盘备份需要手动选择 iCloud 云盘或 Google Drive 桌面版同步文件夹，输入密码后点击立即备份；文件写入成功不代表云端同步已完成。导入时需输入备份密码，导入的分组会追加到现有数据。

开机密码只限制应用界面访问，不加密本地收藏；请妥善保存备份密码。更多操作见 [使用说明](使用说明.md)。

## 项目状态

本项目为试用版。双云盘同步及所有边界情况尚未完整验证，请保留独立备份。网页预览与 App 的数据相互独立。
